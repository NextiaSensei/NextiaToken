### 📊 ESPECIFICACIONES TÉCNICAS DETALLADAS

Motor de Trading:
- Lenguaje: Python 3.8+
- Framework: Custom-built con asyncio
- Base de datos: SQLite (local), PostgreSQL (futuro)
- APIs: Binance REST/WebSocket, Telegram Bot API

Estrategias Implementadas:
1. Mean Reversion (Reversión a la Media)
   - Periodos: 5min, 15min, 1h
   - Indicadores: RSI, Bollinger Bands, Stochastic
   - Eficacia comprobada: 62% win rate

2. Trend Following (Seguimiento de Tendencia)
   - EMA cruzadas: 9/21/50 periodos
   - MACD confirmation
   - Volume analysis

3. Breakout Strategy (Estrategia de Ruptura)
   - Support/Resistance levels
   - Volume breakout confirmation
   - ATR-based targets

        }
        return allocation

5.2 Retiro Automático de Ganancias:

class ProfitWithdrawal:
    def calculate_withdrawal(self, current_balance, initial_balance):
        profit = current_balance - initial_balance
        if profit > 0:
            # 70% se reinvierte, 30% disponible para retiro
            reinvest_amount = profit * 0.7
            available_withdrawal = profit * 0.3
            return reinvest_amount, available_withdrawal
        return 0, 0
